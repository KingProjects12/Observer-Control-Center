# Разбор загруженного dynamic-island-windows-2.1.1.zip

Дата: 24.11.2026. Основа: именно пользовательский архив 2.1.1, не предположения по скриншотам.

## Подтверждённые технические факты

- `DynamicIsland.csproj`: `net10.0-windows10.0.19041.0`, `UseWPF=true`, x64, C#; дополнительно WinForms только для отдельных функций (tray/GDI).
- `MainWindow.xaml` (~105 КБ) — WPF, прозрачное безрамочное Topmost окно; компактное состояние и расширенная панель, собственные компоненты, ресурсные кисти.
- `MainWindow.xaml.cs` (~299 КБ) — состояния окна, spring-анимации ширины/высоты, жесты, системные события. Много partial-классов `MainWindow.*.cs`.
- `Services/Theme.cs` + `themes/themes.json` + `Services/Settings.cs` — оформление, цвета, смена тем, сохранение настроек.
- `.github/workflows/build.yml` — Windows workflow, пакетирование, опциональное подписание и Inno Setup.
- `LICENSE` — MIT, Copyright (c) 2026 mykolaichechelnytskyi.
- Библиотеки оригинала включают NAudio, WebView2, ScreenRecorderLib, ZXing и др.; нам для сетевой консоли они не нужны.

## Рекомендации

**Не форкать Atoll целиком.** Он функционально перегружен под задачи мониторинга и несёт ненужные зависимости (мультимедиа, захват экрана, аудио, ИИ). Сохранить подход к WPF-темам, анимированным состояниям, tray/compact-panel, но сделать минимальный сетевой UI и отдельные бизнес-слои.

**Не мигрировать всё сразу.** Начать с UI + чтения сохранённых результатов, затем с тестами перенести существующий доступ к Keenetic и Excel, после — историю, реестр объектов, поиск событий и дополнительные источники.

**Один EXE реален.** `dotnet publish -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true`, без обрезки сборок WPF. Это не «отказ от .NET», а упаковка runtime вместе с приложением.
