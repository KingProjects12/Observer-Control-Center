# Observer 2.0.4-preview.1 — Island & Motion Fix

## Исправлено

- При возвращении из мини-островка теперь открывается **развёрнутая на весь рабочий экран** консоль (Maximized) вместо принудительного `Normal`.
- Мини-островок **скрывается перед открытием** основной консоли, больше не перекрывает её поверх остальных окон.
- Центр обновлений тоже использует единый путь возврата из островка.
- Предотвращены повторные переключения во время анимации.

## Анимации

- Плавное появление главного окна при запуске (280 мс).
- Переход из консоли в островок: исчезновение консоли и выезд островка (140–250 мс).
- Возврат: уход островка вверх и плавное появление максимизированной консоли.
- Подсветка островка при наведении, мягкое движение и пульсирующий индикатор статуса.

## Не изменено

- Импорт TOP TRAFFIC, данные CSV, фильтры, таблицы и отчёты.
- Оповещения GitHub Release и их проверка версий.
- Прямой опрос Keenetic API в WPF **ещё не реализован**. Для NAT и TOP TRAFFIC используется v1.9.1.

## Что проверить на Windows

1. `Run-Build-Diagnostics.cmd`: 38 тестов, Build succeeded, EXE в `dist`.
2. Запустить EXE, переключиться в островок: большое окно исчезает, островок появляется.
3. Нажать «ОТКРЫТЬ»: островок полностью исчезает, главное окно развёрнуто на весь экран.
4. Повторить переход **5–10 раз**: не должно быть двух одновременно видимых окон.
5. Проверить наведение мыши и статусный индикатор.
6. Проверить Windows Win+Tab/Alt+Tab, сворачивание и повторное раскрытие.
7. Проверить GitHub Updates при открытом и при скрытом главном окне.

Если заметишь ошибки, пришли скриншот и лог `Observer_v2_0_4_Build_...txt`.
