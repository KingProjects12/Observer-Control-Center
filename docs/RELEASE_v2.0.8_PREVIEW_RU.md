# Observer 2.0.8-preview.1 — проверка перед релизом

## Изменения

- **Копировать всё**: специальная кнопка в заголовке журнала; копирует максимум 300 отображаемых строк с временными метками.
- **Выделение фрагментов**: мышью внутри журнала и Ctrl+C, при сохранении цветовой категоризации.
- **Настоящая прозрачность**: главная WPF-консоль использует `AllowsTransparency=True` и полупрозрачную многослойную тему. Через неплотные участки видны другие окна и рабочий стол.
- **Плотность стекла**: кнопка в левом меню переключает «Прозрачно», «Максимум», «Матово».
- **Resize Grip**: в нижнем правом углу окна есть элемент для изменения размера мышью.
- **Сохранено**: иконка Observer, Inno Setup, островок, обновления раз в минуту в тестовом режиме, анализ CSV, цветная консоль.

## Ограничения

Прозрачность означает **альфа-композитинг без системного размытия (Acrylic Blur)**. Для layered WPF окна на некоторых ПК возможны дополнительные затраты GPU/CPU. Тестировать именно на Windows 10/11 с полноэкранным режимом, островком и таблицей 64+ устройств. Live Keenetic NAT/TOP TRAFFIC по-прежнему не мигрированы из v1.9.1.

## GitHub release process

Это **предварительная версия**. Дождаться зелёного CI, испытать на Windows, затем объединить PR #4 с `main`. Публичный стабильный GitHub Release публиковать только после подтверждения. Стабильная версия найдётся в `/releases/latest`; предварительные/черновые релизы этот API не возвращает. Установщик пока без Authenticode-подписи и может вызвать предупреждение SmartScreen. Не отключать Defender.

Готовый preview EXE и установщик доступны во вкладке **Actions → успешный запуск → Artifacts**. ZIP с исходниками на ПК пользователя больше не нужен.
