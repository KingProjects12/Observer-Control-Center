# Observer 2.0.16 — multi-router office NAT
Enter one authorized Keenetic IPv4 address per line (or comma/semicolon-separated), common credentials, and the office /24 locally. Collect NAT runs at most three independent sessions concurrently. It creates one combined CSV and XLSX with original destination matches only and a router-status sheet. Duplicate addresses are removed; observed rows and per-router repeat flags remain. Failure, partial collection or cancellation is visible; completed data is preserved. TOP Traffic and TCP still use one router. Existing VPN required when using VPN REMOTE. No internal addresses or credentials are published. Real router verification remains necessary; NAT can miss VPN/LAN flows.

# Observer 2.0.16 — сбор NAT с нескольких роутеров
Введите IP разрешённых Keenetic по одному на строку (или через запятую/точку с запятой), общие логин и пароль, подсеть офиса /24 локально. «Собрать NAT» запускает до трёх независимых сеансов одновременно. Общий CSV и Excel содержат только исходные адреса назначения в офис, лист статуса роутеров показывает полноту сбора. Повторные IP в списке исключаются, наблюдения и флаги повторов сохраняются. Сбой, частичный результат или отмена не стирают результаты других роутеров. TOP Traffic и TCP пока для одного роутера. VPN должен уже быть подключён. Внутренние адреса и пароли не публикуются. Требуется проверка на реальных роутерах; NAT может не видеть часть VPN/LAN.
