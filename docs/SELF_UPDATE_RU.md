# Self-Update 2.0.10-preview.1

Обновление скачивает только официальный Observer.ControlCenter.exe и SHA-256. После подтверждения временная копия текущей программы ждёт выхода основного процесса, повторно проверяет SHA-256, заменяет EXE в той же папке через File.Replace с резервной копией, запускает новую версию. Мастер установки не используется. При ошибке запуска выполняется попытка возврата. Ярлыки, настройки и CSV не изменяются. Не требуется повышать права. Имя текущего EXE должно оставаться Observer.ControlCenter.exe; папка должна быть доступна на запись. Резервные копии .bak и временный помощник могут остаться на диске. Цифровой подписи пока нет, защита Windows не отключается.

Для перехода с 2.0.9 нужно один раз заменить EXE вручную либо воспользоваться старым механизмом установки. Реальный тест требуется на Windows: скачать следующую стабильную версию из 2.0.10-preview.1, проверить закрытие, замену, перезапуск, SHA-256, сохранение настроек, отмену и отказ при заблокированном файле. Не публиковать стабильный выпуск до проверки CI.
