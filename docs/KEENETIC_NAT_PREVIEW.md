# Keenetic live NAT preview

This first port of the v1.9.1 collector implements x-ndw2 challenge-response, optional host metadata and repeated GET NAT snapshots. Enter the authorized router and target CIDR locally; the repository intentionally contains no internal addresses. HTTPS is the default; HTTP requires explicit confirmation. No router configuration writes, no credentials saved. CSV files include full observations, original-destination matches and office-related evidence. Duplicate five-tuples are marked, not deleted. NAT may omit VPN or LAN traffic; zero matches does not prove absence. x-ndw4 is not supported. TOP TRAFFIC API and XLSX export are still pending. No partial report on interrupted sampling in this initial preview. Windows CI plus actual authorized-router testing required.
