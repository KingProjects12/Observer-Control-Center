# Observer 2.2.0 — modular workspace
Five functional cards (Routers, Connections, TCP, Traffic, Issues), shared connection settings, expandable IP list and advanced parameters, embedded collector and access analyzer, shared selectable color log, real batch progress, stop and retry. Both themes use the same layout. Passwords stay in memory for the current session; HTTP/HTTPS preference is saved locally. Timeout is distinguished from cancellation. Existing report formats and read-only network logic retained. TCP checks remain explicit and authorized. No fabricated speed or user identity metrics. TOP Traffic still accepts one router per operation.
# Observer 2.2.0 — единая рабочая область
Пять модулей, общие настройки подключения, раскрываемый список IP, встроенные сборщик и анализатор, общий цветной журнал, реальный прогресс NAT и остановка. Обе темы сохранены. Пароль только в памяти сессии, выбор HTTP/HTTPS сохраняется локально. Исправлено различие тайм-аута и отмены. Форматы отчётов и сетевое ядро сохранены. TCP отдельно и только при разрешении. TOP Traffic — один роутер за операцию.
