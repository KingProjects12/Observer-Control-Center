# Observer 2.1.1 — оформление Signal
- Вторая матовая тема Signal в тёмно-синей, голубой и лавандовой палитре репозитория.
- Переключатель внизу боковой панели, локальное сохранение выбора, без перезапуска или повторной загрузки отчёта.
- Signal: увеличенные промежутки между кнопками, плавная подсветка выбранной кнопки, цветные KPI-карточки, компактный декоративный баннер. Настоящие таблицы, показатели и журнал сохранены.
- Black Liquid Glass остаётся исходной темой по умолчанию. Сбор, анализ доступов, TCP-проверка, отчёты и механизм обновления не изменены. Это релиз оформления, не исправления безопасности.
