# Observer 2.0.15 — рабочая инструкция

| Группа | Кнопка | Назначение |
|---|---|---|
| Аналитика | Обзор | Сводка загруженного отчёта |
| Аналитика | Соединения | Источник, назначение, порты, протокол |
| Аналитика | TOP Traffic | Рейтинг по объёму |
| Сбор | Подключение / NAT | Логин, пароль, сеть офиса, снимки NAT |
| Сбор | VPN REMOTE | Существующий VPN, не создание туннеля |
| Сбор | Собрать трафик | Период и объём |
| Отчёты | Отчёты / Загрузить CSV | Папка и импорт |
| Система | Инструменты | TCP, акцент, стекло, обновления |
| Система | Справка / F1 | Описание действий |

Для NAT: подключитесь к разрешённой сети, введите адрес роутера и логин/пароль, укажите целевую подсеть /24, нажмите «Собрать NAT». В результатах выберите «В офис», затем «Показать в Observer» или Excel. Пароли не сохраняются. Отчёты и журнал храните локально; проверяйте содержимое перед отправкой. NAT не гарантирует видимость всех VPN/LAN потоков.

В окне сборщика: HTTPS — защищённое соединение с доверенным сертификатом, VPN/TCP — диагностика доступности, Стоп — остановка, Инструменты — центральный CSV и демо. Открыть Excel / отчёты доступны при наличии файлов. В центре обновлений: Проверить сейчас, Обновить и перезапустить, Отмена, Открыть GitHub, Пропустить версию. Все основные действия также описаны внутри приложения.
