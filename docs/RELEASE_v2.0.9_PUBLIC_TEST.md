# Observer Control Center v2.0.9

- Black Liquid Glass: почти непрозрачная чёрная основа, затемнённые панели и таблицы; сохранены три режима стекла, матовый режим полностью непрозрачен.
- Центр обновлений: скачивание официального установщика по подтверждению, прогресс, отмена, проверка размера и SHA-256, запуск штатного мастера.
- Номер версии в заголовке, журнале и подвале берётся из сборки.
- Остальные функции 2.0.8 сохранены; прямые сборщики Keenetic ещё не перенесены.

Публичная тестовая версия. Установщик не имеет доверенной цифровой подписи. Не отключайте защиту Windows. SHA-256 проверяет целостность, а не подпись издателя. Портативная копия не заменяется автоматически. Для теста обновления запустите ранее установленную 2.0.9-preview.1, нажмите «Обновления» → «Проверить сейчас» → «Скачать и установить». Если установленная версия 2.0.8, она только открывает релиз.
