# Observer 2.3.0 — instrument workspace

The visual direction is a calm network instrument: five color-coded modules, neutral surfaces, readable tables, compact settings, persistent action bars and an expandable activity log. Signal is matte; Black Liquid Glass retains neutral translucent layers. No new network scanning features or changes to the collection engine. Windows x64 portable and installer, SHA-256 checksums.

# Observer 2.3.0 — рабочее пространство

Нейтральные поверхности, пять цветных модулей, более читаемые таблицы, отдельные команды запуска и сворачиваемый журнал. Signal — матовый, Black Liquid Glass — полупрозрачный. Сетевое ядро не изменено.

Design methodology adapted from [Unslop](https://github.com/heydamir/unslop) by Damir Sokolovsky (@heydamir), CC BY 4.0. WPF implementation tailored to Observer; approved brand and module colors retained.
