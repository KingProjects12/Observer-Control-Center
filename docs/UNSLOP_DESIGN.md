# Observer instrument workspace

Methodology: [Unslop](https://github.com/heydamir/unslop), Damir Sokolovsky (@heydamir), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Adapted to WPF; no external runtime dependency.

Product: read-only network observation and evidence for authorized administrators.
Character: calm, technical, precise.
World: instruments and network operations.
Moments: five color-coded module controls; actual network evidence.
Signature: thin active-module indicator and semantic event colors.

Audit: decorative gradients/glow, inconsistent spacing and capitalization, duplicate panel outlines, controls hidden inside collapsing settings, visually dense tables. Design passes: spacing, neutral palettes, smaller module glyphs, sentence-case labels, readable typography, separate action bars, reduced outlines, data-first content, short transitions. Black Liquid Glass keeps its neutral glass layers and Signal keeps its cool identity by explicit design choice. No mock metrics, no added scan features. Windows smoke tests cover English/Russian and both themes; visual inspection on a real Windows display remains necessary.
