# Language QA / Проверка языка

Install the same setup twice (English and Russian). Verify all main pages, column headers, logs, glass mode labels, update center and notices, mini island, import dialogs and errors. Restart and test the same language after EXE self-update. Verify registry HKCU\Software\KingProjects12\ObserverControlCenter Language. CSV contents, external GitHub notes without language markers and native OS dialogs are not translated by Observer. Real Windows GUI testing is required.

Установите одну сборку дважды (English и Russian), проверьте интерфейс, журнал, островок, ошибки, перезапуск и сохранение языка при обновлении EXE.
