# Observer 2.0.15 — workspace guide

Analytics: Overview (loaded report summary), Connections (source/destination/ports), TOP Traffic (volume ranking). Collection: Connect/NAT (router credentials and office subnet), VPN REMOTE (existing authorized route), Collect traffic (monitor window). Reports: Reports (local folder), Load CSV (import). System: Tools (TCP, accent, glass, updates), Guide/F1 (in-app explanations).

Collect NAT: enter authorized router, username, password and office /24; collect snapshots, choose To office, then Show in Observer or Open Excel. Existing VPN must already be connected. No passwords stored. NAT cannot prove absence of all LAN/VPN flows. Keep exports private. Collector Tools contains central gateway CSV import and offline demo. Stop cancels collection. Update Center checks releases, downloads a verified EXE, supports cancel, GitHub page and dismissal. Real router and interactive Windows checks remain necessary.
