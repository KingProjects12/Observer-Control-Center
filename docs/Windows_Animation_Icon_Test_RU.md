# Observer 2.0.5 — проверка анимаций, иконки и релизов

Ветка предназначена для проверки. Релиз не публикуется автоматически после каждого коммита.

## Изменения

- Плавные переходы между разделами консоли.
- Лёгкая анимация навигации и карточек KPI, подсветка строк таблицы.
- Появление системного и внутриоконного уведомления об обновлении.
- Сохраняются исправленные переходы между островком и главным окном.
- Сборщик на Windows сам генерирует и встраивает иконку Observer (16, 32, 48, 256 пикселей).
- GitHub Actions прикладывает self-contained win-x64 EXE как артефакт проверенной PR-сборки.
- Выпуск GitHub Release запускается из Actions → Publish Observer Windows EXE → Run workflow после ввода версии.

## Проверки на Windows

1. Скачать артефакт Observer-preview-win-x64 с успешной сборки PR или локально собрать Run-Build-Diagnostics.cmd.
2. Проверить иконку файла EXE в Проводнике и на панели задач.
3. Несколько раз быстро переключить Обзор / TOP Traffic / Соединения и проверить плавность анимаций.
4. Навести курсор на карточки и кнопки; убедиться, что текст и таблицы не сдвигаются.
5. Несколько раз перейти из консоли в островок и обратно. Островок не должен висеть поверх открытой консоли.
6. Открыть центр обновлений; после будущего релиза проверить уведомление.
7. Закрыть и повторно запустить приложение, проверить журнал на ошибки.

## Ограничения

- 2.0.5 — пока WPF preview с импортом CSV, не заменяет v1.9.1 для прямого сбора NAT и TOP TRAFFIC.
- Публичные релизы не выпускаются при обычном push; нужен осознанный запуск workflow или тег.
- Не публиковать корпоративные IP, пароли, сырые JSON и реальные выгрузки.
- Сливать ветку в main только после зелёной сборки и теста интерфейса на Windows.
