# Collector integration

Open Connect / NAT, enter the authorized router IPv4, username, password, select HTTPS (recommended) or explicitly approve HTTP within a trusted network, enter the office network in canonical /24 CIDR notation, choose snapshots and interval, then collect NAT. VPN REMOTE restricts endpoints to internal address ranges and uses the existing network path. It does not create or modify a VPN. TOP Traffic reads one selected monitor window. Tools opens secondary operations. Choose a report in the collector and Show in Observer, or open Excel / reports. Keep raw JSON and exported data private. The old collector core is reused with a JSON compatibility layer for .NET 10, a locally configurable target, and anonymized offline fixtures. Offline tests include original v1.9.1 NAT, auth, VPN, partial-report, evidence, central import, traffic and export fixtures. Windows GUI and actual authorized Keenetic testing remain necessary. x-ndw4 is not implemented. No changes to router settings.
