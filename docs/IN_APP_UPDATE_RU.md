# Обновление из Observer 2.0.9

В центре обновлений после обнаружения нового стабильного официального релиза появляется «СКАЧАТЬ И УСТАНОВИТЬ». После подтверждения загрузка идёт с индикатором прогресса и отменой. Проверяются размер и SHA-256, затем запускается обычный установщик Windows и Observer завершает работу. Запуск после установки предлагает мастер Inno Setup. Если загрузка или проверка не удалась, текущая программа продолжает работать. Для portable EXE запускается обычная установка; portable-файл не заменяется.

Доверенная Authenticode-подпись пока отсутствует: SHA-256 проверяет целостность, но не заменяет подпись. Не отключайте SmartScreen или Defender. Установщик остаётся во временной папке после успешного запуска, чтобы мастер мог читать его; очистить можно после завершения установки.

Для теста: установить сборку 2.0.9-preview.1, затем обнаружить опубликованный стабильный v2.0.9 или более новый релиз. Проверить отмену, обрыв сети, SHA-256, запуск мастера, сохранение настроек, перезапуск и номер версии. Старые версии не получают кнопку до ручной установки новой сборки.
