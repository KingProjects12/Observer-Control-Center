## Описание выпуска для GitHub Releases

**Observer 2.0.7 — Black Liquid Glass (desktop preview)**

В этом выпуске мы превратили переносимую WPF-сборку в устанавливаемое Windows-приложение:

- Новый чёрный Liquid Glass-inspired интерфейс с бирюзовыми акцентами.
- Тёмные стилизованные полосы прокрутки.
- Цветные сообщения журнала: успех — зелёный, ошибка — красный, системные операции — синий, предупреждения — янтарный.
- Новая Windows-иконка в EXE и в заголовках окон.
- Установщик Inno Setup: ярлыки, повторная установка/обновление, штатное удаление.
- Автоматическая сборка установщика и переносимого EXE в GitHub Actions, SHA-256 рядом с файлами.
- Временная проверка GitHub Releases каждые 60 секунд; при ограничениях API выполняется пауза.

### Файлы для загрузки

- `Observer-Control-Center-Setup-2.0.7-win-x64.exe` — рекомендуется; устанавливает приложение в профиль пользователя.
- `Observer.ControlCenter.exe` — переносимая версия.
- `*.sha256` — контрольные суммы файлов.

### Что уже работает

WPF-консоль, мини-островок, цветные журналы, CSV-анализ трафика, локальные проверки TCP, уведомления о GitHub Releases.

### Ограничения

- **Это desktop preview, не полноценный live-монитор сети.** Прямой сбор Keenetic NAT и TOP TRAFFIC из v1.9.1 **ещё не перенесён**.
- Установщик и EXE пока не подписаны доверенной цифровой подписью: Microsoft SmartScreen может показать предупреждение. Не отключайте Defender.
- Программа не выполняет фоновую принудительную загрузку, установку или запуск обновлений; система уведомляет и открывает официальный GitHub Release.

## Как выпустить после полного подтверждения

1. Убедиться, что PR #4 готов, новый GitHub Actions check зелёный, и объединить ветку с `main`.
2. Открыть **Actions → Publish Observer installer and portable EXE to GitHub Releases → Run workflow**.
3. Выбрать ветку **main** и ввести **v2.0.7**.
4. Дождаться сборки обоих файлов, проверить SHA-256, описание и страницу Release.
5. На установленном `2.0.6-preview.1` открыть **Обновления → Проверить сейчас**. Запрос `/releases/latest` увидит только стабильный опубликованный Release (draft/prerelease не подходят).
6. Отдельно вручную проверить обновление через скачанный установщик. Программа пока НЕ выполняет автоматическую установку из UI.

**Внимание:** стабильный GitHub Release будет публичным; не публиковать его, пока дизайн не подтверждён. Прямой сбор Keenetic не включён.
