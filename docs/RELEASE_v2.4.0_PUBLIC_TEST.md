# Observer 2.4.0 — Theme gallery

Open Settings → Themes to select from 18 themes, with custom vector previews, instant theme application and per-user preference persistence. Spring, Summer, Autumn, Winter, New Year, Midnight, Graphite, Ocean, Forest, Sunset, Rose, Lavender, Aurora, Nebula, Ember and Arctic join the original Signal and Black Liquid Glass. Winter and New Year support optional animated snow in the header; the Effects tab can disable it. Windows animation settings are respected. No changes to networking or report processing.

# Observer 2.4.0 — Галерея тем

Настройки → Темы: 18 вариантов оформления, карточки предпросмотра, мгновенное применение и сохранение выбора. В темах «Зима» и «Новый год» доступен снег в шапке. Эффект отключается во вкладке «Эффекты». Сетевое ядро и формирование отчётов не изменены.
