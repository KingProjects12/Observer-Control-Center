# Observer media / Графика Observer

The SVG files here are original repository branding assets, with dark and light variants. The hero has declarative SVG pulse animation (static fallback in clients that do not render animation). The dashboard is a concept, not an application screenshot. No production network data was used.

Настоящие скриншоты и GIF работы приложения должны быть записаны с синтетическими данными или полностью обезличены. Не публикуйте внутренние адреса, имена устройств, учётные данные, пути с именами пользователей и клиентские отчёты. Логотип README не изменяет иконку установленного приложения.
