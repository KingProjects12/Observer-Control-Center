# Observer 2.0.13 — interface organization
- Grouped sidebar: Analytics, Collection, Reports, System. Secondary commands remain in Tools.
- Collector cards: Connection, Collection settings, Actions, Results, Activity; copyable diagnostic log.
- Shared dark glass templates for buttons (including disabled state), checkboxes, progress, password inputs, selection lists and menus.
- No collector engine, VPN, TOP Traffic, export, authentication or self-update algorithm changes. Windows visual and authorized router regression testing required.

# Observer 2.0.13 — организация интерфейса
- Меню разделено на аналитику, сбор данных, отчёты и систему. Дополнительные действия — в инструментах.
- Окно сборщика разделено на подключение, параметры, действия, результаты и журнал; добавлено копирование журнала.
- Единый тёмный стиль кнопок (включая отключённые), чекбоксов, прогресса, паролей, списков и меню.
- Ядро NAT/VPN/TOP Traffic, экспорт, вход и алгоритм обновления не изменены. Требуется визуальный тест Windows и проверка на разрешённом роутере.
