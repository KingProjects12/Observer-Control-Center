# Observer Control Center v2.0.8 — публичная тестовая версия

**Первый выпуск через GitHub Releases.** С этого релиза установленный Observer сможет обнаруживать новые версии через кнопку «Обновления» и автоматическую проверку.

## В этом выпуске

- Black Liquid Glass: настоящее полупрозрачное окно WPF, регулируемая плотность стекла («Прозрачно», «Максимум», «Матово»); без системного размытия Acrylic
- Журнал событий с выделением фрагментов мышью и копированием через Ctrl+C
- Кнопка «КОПИРОВАТЬ ВСЁ» для копирования до 300 отображаемых строк журнала вместе с временными метками
- Цветная классификация событий: зелёный, красный, синий и янтарный
- Новая иконка Observer, тёмные полосы прокрутки, анимации мини-островка
- Windows-установщик Inno Setup с ярлыками, обновлением установленной программы и штатным удалением
- Приложение для Windows x64, самодостаточный EXE без отдельной установки .NET

## Загрузка

Для обычной установки используй файл **Observer-Control-Center-Setup-2.0.8-win-x64.exe** из Assets. Для запуска без установки — **Observer.ControlCenter.exe**. Проверить целостность можно с помощью вложенных SHA-256 файлов.

## Важно: возможности и ограничения

Это **публичный тестовый выпуск интерфейса**, не полностью готовая промышленная система мониторинга сети.

- WPF-консоль пока импортирует готовые CSV-отчёты. Прямые сборщики Keenetic NAT и TOP TRAFFIC из рабочей v1.9.1 **ещё не перенесены**.
- Программа **не обновляется принудительно** и не устанавливает обновления сама: она уведомляет об опубликованной версии и открывает официальный GitHub Release.
- Установщик и EXE **пока не имеют доверенной подписи Authenticode**. Microsoft Defender SmartScreen может предупредить о неизвестном издателе. Не отключай Windows Defender.
- Прозрачность выполнена средствами WPF; на некоторых системах она может влиять на плавность интерфейса. Проверь работу островка и полноэкранного режима.

## Обновление с предыдущей версии

В Observer 2.0.7-preview.1 открой «Обновления», убедись, что указано `KingProjects12/Observer-Control-Center`, и нажми «Проверить сейчас». После публикации этого выпуска программа должна обнаружить `v2.0.8`. Для обновления скачай установщик с GitHub Releases и запусти его после закрытия прежнего Observer.
